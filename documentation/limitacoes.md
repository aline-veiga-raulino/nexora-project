# ⚠️ Limitações e qualidade dos dados

## 🧪 Escopo do case

A análise considera uma base comercial referente exclusivamente ao ano de 2020.

## 🆔 Ausência de identificador de transação

A base não possui um ID único de venda.

Foram observados registros com os mesmos valores em todos os campos analisados. Sem um identificador de transação, não é possível determinar apenas pela estrutura da base se esses registros representam vendas distintas ou duplicidades.

Por isso, os registros não foram removidos automaticamente.

## 📅 Escopo temporal

A base contém somente 2020. Não é possível realizar comparações anuais ou análises de crescimento entre anos.

## 🗂️ Variáveis disponíveis

A base não contém informações sobre:

- clientes;
- região;
- canal de venda;
- metas;
- custo detalhado;
- horário da venda.

Essas variáveis limitam análises de segmentação, rentabilidade e causa.

## 🔎 Natureza das conclusões

As conclusões apresentadas são descritivas e baseadas nos dados disponíveis. Quando uma causa não pode ser comprovada pela base, ela é tratada como uma questão para investigação futura.
